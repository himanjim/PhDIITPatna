# Frontend documentation

This directory contains supporting documents for the frontend demo and its
backend and API integration assumptions.

## Contents

- `UI_Setup_Testing_and_Performance_Measurement_Methods.docx` records how the
  demo is set up, how it is tested, and the procedure behind the performance
  figures in `perf/`.
- `hyperledger-web-api-setup.docx` records the web API setup the demo assumes
  when the mock backend is replaced by a real gateway.

## Notes

- The two filenames follow different conventions, one using underscores and
  title case and the other using hyphens and lower case. Leave them as they are.
  Filenames in this repository are cited from the thesis components by their
  exact path, so renaming a file silently breaks a reference. Apply a single
  convention only as part of a deliberate pass that updates the citations at the
  same time.
